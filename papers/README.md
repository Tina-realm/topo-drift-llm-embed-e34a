# Downloaded Papers

## Core Baseline Papers

1. **MMD Aggregated Two-Sample Test** (schrab2021_mmd_aggregated_two_sample_test.pdf)
   - Authors: Schrab, Kim, Albert, Laurent, Guedj, Gretton
   - Year: 2023 (JMLR)
   - arXiv: 2110.15073
   - Why relevant: Primary baseline -- strongest off-the-shelf kernel test with adaptive bandwidth selection

2. **Learning Deep Kernels for Non-Parametric Two-Sample Tests** (liu2020_deep_kernel_two_sample_test.pdf)
   - Authors: Liu, Xu, Lu, Zhang, Gretton, Sutherland
   - Year: 2020 (ICML)
   - arXiv: 2002.09116
   - Why relevant: Deep kernel MMD baseline -- learns spatially-varying kernels via neural networks

3. **Revisiting Classifier Two-Sample Tests** (lopez-paz2017_classifier_two_sample_test.pdf)
   - Authors: Lopez-Paz, Oquab
   - Year: 2017 (ICLR)
   - arXiv: 1610.06545
   - Why relevant: C2ST baseline -- uses classifier accuracy as test statistic

4. **A Kernel Two-Sample Test** (gretton2012_kernel_two_sample_test_mmd.pdf)
   - Authors: Gretton, Borgwardt, Rasch, Scholkopf, Smola
   - Year: 2012 (JMLR)
   - arXiv: 0805.2368
   - Why relevant: Foundational MMD paper -- defines MMD metric and tests

## Topological Data Analysis Papers

5. **Two-sample Tests for Relevant Differences in Persistence Diagrams** (krebs2024_two_sample_test_persistence_diagrams.pdf)
   - Authors: Krebs, Rademacher
   - Year: 2024
   - arXiv: 2401.10349
   - Why relevant: Directly relevant -- two-sample tests using Wasserstein distance on persistence diagrams

6. **Hypothesis Testing for Topological Data Analysis** (hypothesis_testing_topological_data_analysis.pdf)
   - arXiv: 1310.7467
   - Why relevant: Foundational statistical framework for TDA hypothesis testing
